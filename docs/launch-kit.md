# SopKit Launch Kit

Everything needed to launch and distribute SopKit (600+ free, privacy-first, browser-based tools).
Base URL: https://sopkit.space

---

## 1. Show HN Post Draft

**Title:** `Show HN: SopKit – 600+ free online tools that never upload your data`

**Pitch (3 sentences):**

> I built SopKit because every "free online tool" site I tried wanted an account, watermarked the
> output, or quietly uploaded my files to a server. All 600+ tools here — PDF merge/split/compress,
> image resizing, JSON formatting, unit converters, QR codes — run entirely client-side in your
> browser using JavaScript/WASM, so your data literally cannot leave your device. It's free with no
> signup or usage caps, open about how each tool works, and I'd genuinely appreciate feedback on
> which tools to build next.

**Posting notes:**
- Post Tuesday–Thursday, 7–9 AM ET for best visibility.
- First comment: mention the stack (Next.js static export on GitHub Pages) and invite nitpicks.
- Reply to every comment within the first 3 hours; honesty about limitations beats marketing.
- Do not mention monetization unless asked; if asked, answer plainly (ads on non-tool pages).

## 2. Product Hunt Copy

**Tagline (<=60 chars):**
`600+ free private tools that run in your browser` (48 chars)

**Description:**
SopKit is a library of 600+ free online tools — image compression, PDF editing, file converters,
developer utilities, SEO checkers, calculators — that process everything locally in your browser.
No accounts, no uploads, no daily limits. Open a tool, get your result, done.

**5 Highlights:**
1. **Privacy by architecture** — files are processed client-side; nothing is uploaded to any server.
2. **600+ tools in one place** — image, PDF, video, audio, text, developer, SEO, finance, and more.
3. **Zero friction** — no signup, no watermark, no usage caps, works on mobile.
4. **Embeddable widgets** — add any of 12 popular tools to your own site with one iframe snippet (/embed-tools).
5. **Fast & lightweight** — static pages served from GitHub Pages load instantly worldwide.

## 3. Directory Submission Checklist

Work top-down; tick items as you go. Use one consistent listing: name, tagline above,
description above, https://sopkit.space, og-image.jpg as screenshot.

- [ ] **AlternativeTo** — https://alternativeto.net — submit as alternative to iLovePDF, Smallpdf,
      Canva, and Online-Convert. List ~5 concrete app features. One submission per persona account.
- [ ] **ToolFinder** — https://toolfinder.co — pitch via their "suggest a tool" page; emphasize
      the privacy angle they curate for.
- [ ] **free-for.dev** — https://free-for.dev — PR against their GitHub repo adding SopKit under
      the relevant "tools/services" sections; keep the diff minimal.
- [ ] **GitHub awesome lists** — PRs to:
      - awesome-online-tools style lists (search GitHub topic: awesome + online-tools)
      - https://github.com/sindresorhus/awesome (only via a sub-list inclusion)
      Follow each repo's CONTRIBUTING.md; alphabetical order; one link per PR.
- [ ] **Reddit r/InternetIsBeautiful** — https://reddit.com/r/InternetIsBeautiful
      Etiquette: post as a discovery ("I made a site where..."), no link shorteners, respond to
      comments, never repost within 6 months, read sidebar rules (no self-promo spam).
- [ ] **Reddit r/SideProject** — https://reddit.com/r/SideProject
      Etiquette: self-promo is welcome here but give context — what you built, stack, what you
      learned. Engage with other projects too before/after posting.
- [ ] Bonus low-effort: Hacker News "Ask" follow-ups, Product Hunt forums, BetaList, Uneed.best,
      Peerlist Launchpad.
